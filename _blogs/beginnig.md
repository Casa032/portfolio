Why I build this GitHub page?

## Why GitHub pages?

I was looking for a way to share and keep a record of projects I had worked on in the past, as well as projects I am currently working on. GitHub Pages seemed like one of the best alternatives because it allows me to host a website without having to deal with traditional web hosting.

[GitHub pages](https://docs.github.com/fr/pages/getting-started-with-github-pages/what-is-github-pages)

## Why Jekyll ?

I chose Jekyll for a similar reason. Jekyll is a static site generator that can be used to build a website from Markdown, HTML, layouts, and other files. I combined it with some CSS and JavaScript to customize the site.

It simplifies the process of creating and maintaining a website, especially if you have a basic understanding of its configuration.

[Jekyll documentation](https://jekyllrb.com/docs/)
